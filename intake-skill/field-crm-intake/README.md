# Field CRM intake (Claude skill)

Works through what Field CRM has finished: each call or quote request gets
its report, its emails as Outlook drafts (never sent) and its follow-ups,
using the end-game, quote request and visit planner skills, then a review
page. Start with `DOCUMENTATION.md`.

- `SKILL.md`: what Claude follows.
- `scripts/`: `list_tickets.py`, `to_quote.py`, `draft_email.py`, `done.py`,
  `review.py`, `check_setup.py`, `self_test.py`.
- `examples/`: a made-up ticket, call file, settings and handled record.

Made-up data only (Example Foods, Jo Bloggs).
